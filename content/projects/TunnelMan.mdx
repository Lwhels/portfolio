A 2D arcade-style grid game developed in C++ for UCLA CS 32 (Data Structures and Object-Oriented Programming).

## Key Features

- **Inheritance & Polymorphism:** Architected base `Actor` abstract class with derived implementations for `TunnelMan`, `Protester`, `GoldNugget`, `Boulder`, and `Squirt`.
- **Enemy AI & Pathfinding:** Implemented BFS queue-based shortest path algorithms for enemy Protesters navigating around dirt and boulders.
- **Collision & Physics:** Developed precise grid collision detection, gravity mechanics for falling boulders, and item pickup logic.

## Built With

- [C++](https://isocpp.org/)
- Object-Oriented Design Patterns
