SongSwipe is a hackathon project built during the LA Hacks collegiate hackathon. The application connects music fans through an interactive card-swiping interface that presents top tracks retrieved via the Spotify Web API.

## Key Features

- **Spotify Web API Integration:** Authenticates users via OAuth to retrieve their top 5 artists and most-played tracks.
- **Card-Swiping Matching Interface:** Interactive gesture-driven card deck enabling users to listen to 30-second song previews and swipe right to match with other listeners with compatible music taste.
- **Real-Time Match Chat:** Once two users match on common tracks, the platform enables direct messaging to share playlists and song recommendations.
