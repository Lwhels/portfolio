A C++ systems programming project implementing a mountable EXT2 file system driver for the Linux kernel as part of UCLA CS 111 (Operating Systems).

## Key Features

- **Inode Management:** Handles inode allocation, deallocation, and metadata tracking across disk blocks.
- **Directory Traversal:** Supports hierarchical file lookup, directory entry reading, and path resolution.
- **Block Addressing:** Implements direct, singly-indirect, and doubly-indirect block mapping for large file access.

- [C++](https://isocpp.org/)
- [Linux Kernel](https://www.kernel.org/)
