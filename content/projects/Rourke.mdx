RourkePalmer.com is a production e-commerce and media streaming web application built to support the release and merchandise distribution for sci-fi author Rourke Palmer.

## Key Features

- **Authentication & Role-Based Access:** Employs Firebase Authentication with custom claims separating conventional readers from administrative content managers.
- **Data & Media Persistence:** Stores merchandise catalog metadata and chapter details in Cloud Firestore, with high-resolution digital media assets served from Firebase Storage.
- **Stripe Payments Integration:** Integrated Stripe Checkout API for secure transactions, order fulfillment tracking, and webhook-driven purchase confirmation.
- **Transactional & Marketing Email:** Configured AWS SES (Simple Email Service) and Nodemailer to handle order receipts and broadcast subscriber newsletters.
- **Fluid Motion & Responsive Design:** Designed in Figma and developed with Next.js, TypeScript, Tailwind CSS, and Framer Motion for responsive mobile and desktop viewing.
