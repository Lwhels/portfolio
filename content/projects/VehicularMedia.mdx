VehicularMedia.com is a production portfolio and client intake web platform designed for an automotive media specialist and social media management agency.

## Key Features

- **Automotive Media Showcase:** Responsive gallery featuring high-resolution photography and automotive video reels organized by automotive campaigns.
- **Transactional Inquiries Pipeline:** Serverless contact pipeline powered by AWS SES and Nodemailer for direct client inquiries and booking requests.
- **Media Asset Storage:** Integrated AWS S3 for scalable cloud hosting and high-bandwidth delivery of automotive media assets.
- **Fluid Motion & Adaptive UI:** Implemented using Next.js 14, Tailwind CSS, DaisyUI, and Framer Motion for cross-device mobile and desktop experiences.
- **Automated Testing Suite:** End-to-end and component test coverage implemented using Playwright, Jest, and Testing Library.
