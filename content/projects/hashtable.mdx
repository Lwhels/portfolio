A concurrent systems programming project for UCLA CS 111 (Operating Systems) implementing high-performance thread-safe hash tables in C++.

## Key Features

- **Fine-Grained Locking:** Replaced global coarse-grained table locks with per-bucket mutex locks to drastically reduce thread contention.
- **Multithreaded Benchmarking:** Evaluated read/write throughput and latency across varying worker thread counts under heavy parallel workload.
- **Race Condition Safety:** Verified thread safety against data races and memory corruption using ThreadSanitizer.

## Built With

- [C++](https://isocpp.org/)
- `std::mutex` & POSIX Threads
- ThreadSanitizer
